Hello there!


Welcome to my folder of PowerShell Scripts concerning remote diagnostics via Ninja. These were designed to be run through NinjaOne Automation and collect information 
on endpoints without interrupting the users. All these scripts produce files that could then be downloaded through Ninja for technicians to analyze. 

The following is a list of some of the scripts contained herein:

1. Event Viewer Analyzer     (past 48hrs)(Includes sorted sheets)(XML file produced)
2. Storage Sizes Analyzer    (Records all folders over 5Gb and files over 1Gb)(txt file produced)
3. Storage Structure Mapper  (Records all folders and files, with sizes noted in names, builds a expandable tree in html)(C Drive and All Drives versions, can include exclusions)(html file produced)
